# Travel workbench: 旅行决策与记录

2026-11-11。Operate 模式。四项扩展已按用户授权替换正式 Preact 界面；六个核心规划场景保留为可点击设计稿。整套界面的最终视觉认可、真实宿主和公开发布验收尚未完成。架构与接线状态以 [17](../../wiki/current/17-openai-travel-architecture.md) 和 [18](../../wiki/current/18-openai-travel-development.md) 为准。

## 方向与范围

**THESIS：**旅行者先看懂整趟选择，再处理每日安排与连带变化；记录和共享延续同一趟旅行，不另造聊天或旅行状态。

**OWN-WORLD：**沿用当代博物馆访客信息的清楚标题、选项边界和比较行。瓷白与纯白承载内容，石墨文字建立层级，朱红表达主动作和当前选择。系统无衬线字体、原生表单和内联 Phosphor SVG（MIT）；照片与三维内容承担表达，不添加装饰地图、纸张纹理或营销式版面。被否定的蓝绿原型和旧 map-pulse 风格仅为历史证据，不再指导设计。

**FORM：**code-led，沿用既有 `seed:d51a01aae03eedc2`（reroll 1）；本次未重新抽取方向。具体 token 与可复用规则见 [DESIGN.md](../../DESIGN.md)。

用户在 Codex／ChatGPT 的宿主对话中提出需求，插件内选择、编辑与确认。Java／PostgreSQL 是云端旅行的服务边界，Preact 复用注册组件；这里的视觉调整不证明目标架构已全部实现。

## 六个规划场景：设计稿

| 阶段 | 旅行者的决定 | 设计要求 |
| --- | --- | --- |
| 整趟方向 | 先比较两三个住宿与移动方案 | 相同问题并列比较，选择方向后才展开每日细节 |
| 每日安排 | 看懂当天顺序和可调整之处 | 到访与地图联动，保留日期、同行人和已订交通 |
| 比较备选 | 决定替换哪项安排 | 同时看到时间、位置、费用和适用条件 |
| 连带影响 | 接受哪些后续变化 | 显示原安排与改动行，确认后一起更新试排 |
| 审阅采用 | 知悉具体未知条件后决定采用 | 暂定与已核验分开，锁定项和风险覆盖缺口持续可见 |
| Today | 判断下一步与变化影响 | 保留采用版，先展示建议与影响，再由用户确认 |

这些页面的编排与交互仍属于 [设计目录](../../design/2026-11-11-user-journey-review/README.md)，不能据此声称方向选择、完整地图、完整比较或连带更新已接线。现有服务的首次暂定采用、每日安排和天气跟进是独立已实现范围，具体限制见 18。

## 四项扩展：正式组件

| 场景 | 可见路径与保存边界 |
| --- | --- |
| 照片手账 | 从旅行、日期或到访进入；可纯文字，可后补日期与地点；明确新建、保存、编辑、排序与删除 |
| 照片浮雕 | 选中照片后本机预览；明确“保存效果”才更新同一照片；源图片不变，未保存离开有选择 |
| 目的地沉浸 | 旋转、缩放、切换地点与章节、开始或暂停导览，再回到原旅行；不因此修改安排 |
| 共享授权 | 查找已注册且 Google 已验证邮箱对应的账号，核对身份与查看／编辑影响后授权；可改权限或撤销 |

记录保留独立版本，照片保留稳定身份，排序不改变照片归属；每条最多三张照片，每趟最多四十条记录。查看者不能保存效果或删除，编辑者不能管理共享；只有拥有者能授权和撤权。非 Google 托管邮箱提示再次核对当前账号归属。保存冲突保留本地编辑，结果未知按原次操作恢复，不重新创建记录或授权。

## 首屏与跨端

**FIRST VIEWPORT：**手账首先展示已保存的照片／文字画廊、日期筛选和新建动作。打开编辑侧层后，唯一任务标题是“新建旅行记录”或“编辑旅行记录”；表单内不再重复手账页标题。浮雕首先展示所选照片及可操作的预览，共享首先展示当前成员与权限范围。

桌面手账三列，受宿主宽度约束后降为两列；宽编辑侧层将内容与日期／到访分栏。手机手账单列，编辑与其他侧层铺满视口，内容独立滚动，头尾动作保持可见。标准侧层最大宽（680px），宽侧层最大宽（1100px），宽侧层在（1020px）以下占满；（650px）以下切为手机布局。沉浸场景与章节在（820px）以下改为上下排列。

新媒体控件保持清楚的键盘焦点；打开侧层后焦点进入任务标题，关闭回到触发位置。未保存内容有继续编辑或放弃的选择；保存中的操作不能被随意打断。

## 实现与证据边界

四项扩展直接复用 `JournalPanel`、`PhotoRelief`、`DestinationExperience`、`SharingPanel` 与 `Sheet`。设计目录中的 `media.jsx` 只提供带标识的内存宿主，刷新重置；正式插件不引入该夹具。六个规划场景的旅行、价格、交通与天气是合成情景，素材来源和许可在设计目录保留。

本轮已有桌面、390px 手机视口与 861px 工作区的实际操作及目测记录。真实 Java／MCP／临时 PostgreSQL 浏览器路径验证了照片上传、保存和整页回读、浮雕效果保存与源图片比对、排序，以及共享查看、编辑和撤权后的媒体拒绝；账号与旅行来源为合成输入。该记录来自 [本轮观察文件](../../design/2026-11-11-user-journey-review/screenshots/media-observations.json)，不是本文件新增执行的验收。

尚未验证真实 Google 登录、Codex／ChatGPT 原生入口、物理手机、授权旅行来源或公开插件发布。风格化三维不是现场扫描、路线或开放条件证据；本机服务成功也不等于这些外部路径通过。
