# WorkBuddy 连接器

按官方 MCP + Skill 格式打包，使用标准 MCP OAuth；不写入长期凭据。部署旅行服务后运行根目录 `npm run plugins:pack -- --origin=https://your-service.example` 替换地址。

在 WorkBuddy 开放平台提交连接器包；审核、可信 Origin 与实际客户端连接仍需完成。Buddy 应用支持 MCP Apps，但此包不等于已获得应用 ID 或上架资格。

规范：https://open.workbuddy.cn/docs/connector ，https://open.workbuddy.cn/docs/buddy-app 。
